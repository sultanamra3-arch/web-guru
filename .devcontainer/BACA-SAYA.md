# Uji coba SiGuru di Codespaces

1. Tunggu sampai persiapan selesai (±2–3 menit pertama kali).
2. Buka tab **PORTS** → baris **SiGuru (8080)** → klik ikon 🌐 (Open in Browser).
   Bila belum muncul, jalankan di Terminal: `bash .devcontainer/jalankan.sh`
3. Masuk dengan **admin / admin123** (akun guru lain: guru / guru123).

Semua data di sini contoh (nama siswa fiktif) dan hanya ada di Codespace ini.
Untuk mencoba fitur AI: Lainnya → ⚙ Pengaturan AI → isi kunci API (tersimpan di Codespace ini saja).

Matikan Codespace bila selesai agar kuota gratis tidak habis:
github.com/codespaces → ⋯ → Stop codespace.
