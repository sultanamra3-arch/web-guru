Cara dapat kunci gratis (cukup login akun Google/email, tanpa kartu kredit):

  1. Gemini (paling disarankan, bisa baca foto): buka aistudio.google.com/apikey → Create API key → salin.
  2. Groq (cadangan, cepat): console.groq.com/keys → Create API Key.
  3. OpenRouter (cadangan): hanya model berakhiran :free yang dipakai, jadi saldo tidak pernah terpotong.
  4. Cerebras, SambaNova, NVIDIA, Mistral: cadangan tambahan, gratis. Cukup tempel kunci; kolom Model boleh dikosongkan, nanti dipilih otomatis.

AI dicoba berurutan dari nomor terkecil. Jika limit satu AI habis, otomatis pindah ke berikutnya. Cukup satu akun per layanan.
